# Dokumentasi Program TP2

Disarankan mengambil 2 screenshot untuk setiap bahasa:

1. **Awal:** tampilan yang menunjukkan 5 object awal.
2. **Setelah Add:** tampilan setelah data Encanto berhasil ditambahkan sehingga jumlah data menjadi 6.

Nama file yang disarankan:

```text

```
